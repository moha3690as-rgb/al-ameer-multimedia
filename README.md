# شركة الأمير للمالتي ميديا — AL AMEER MULTIMEDIA

تطبيق ويب متكامل (Frontend + Backend + Database + Admin Dashboard + Authentication + PWA)
مبني بالكامل بلغة Node.js **بدون أي مكتبات خارجية** (لا npm install مطلوب)، باستخدام:
- خادم HTTP أصلي من Node (`http`)
- قاعدة بيانات SQLite مدمجة في Node (`node:sqlite`)
- تشفير كلمات المرور عبر `crypto.scrypt`
- جلسات دخول موقّعة (HMAC) بدون مكتبات JWT خارجية

هذا الاختيار التقني مقصود: أي بيئة استضافة تدعم Node.js 22+ ستشغّل المشروع فورًا دون مشاكل توافق حزم.

---

## 1. التشغيل محليًا

**المتطلبات:** Node.js نسخة 22.5 أو أحدث فقط (لا حاجة لأي شيء آخر).

```bash
cd al-ameer
node server.js
```

عند أول تشغيل سيقوم الخادم تلقائيًا بـ:
- إنشاء قاعدة البيانات `data/ameer.db`
- زرع بيانات تجريبية للخدمات والأعمال
- إنشاء حساب **Super Admin** أول مرة فقط، وطباعة بريده وكلمة مروره المؤقتة في الطرفية (Terminal) — **انسخها فورًا**، فهي تُطبع مرة واحدة فقط ولا تُخزَّن كنص عادي (يتم تجزئتها/Hashing قبل الحفظ).

بعدها افتح:
- الموقع: `http://localhost:3000`
- لوحة الإدارة: `http://localhost:3000/admin/login.html`

> إذا فاتتك كلمة المرور المطبوعة أول مرة، احذف ملف `data/ameer.db` وأعد التشغيل ليُنشئ حسابًا جديدًا (سيفقد هذا أي بيانات أدخلتها — لإعادة تعيين كلمة المرور فقط دون فقدان البيانات، عدّلها لاحقًا عبر كود بسيط أو أضف مستخدمًا جديدًا يدويًا).

للتشغيل مع إعادة تحميل تلقائي أثناء التطوير:
```bash
npm run dev
```

## 2. البناء للإنتاج (Production)

بما أن المشروع بدون أي خطوة Build أو Bundler (HTML/CSS/JS عادي من جهة الواجهة، و Node عادي من جهة الخادم)، فـ"البناء" هنا يعني فقط تجهيز بيئة التشغيل:

```bash
# على الخادم:
git clone <repo-url> al-ameer
cd al-ameer
NODE_ENV=production PORT=3000 node server.js
```

يُفضّل تشغيله خلف مدير عمليات مثل **pm2** ليعيد تشغيله تلقائيًا عند الأعطال:
```bash
npm install -g pm2   # مرة واحدة على الخادم
pm2 start server.js --name ameer-multimedia
pm2 save
```

### متغيرات البيئة (Environment Variables)
| المتغير | الوصف | افتراضي |
|---|---|---|
| `PORT` | المنفذ الذي يستمع عليه الخادم | `3000` |

لا يوجد أي مفتاح API أو كلمة مرور مطلوبة في متغيرات البيئة — سر توقيع الجلسات (`data/.session-secret`) يُولَّد تلقائيًا عند أول تشغيل ويبقى على القرص؛ **لا تضعه في Git** (موجود في `.gitignore`).

### HTTPS
هذا الخادم يعمل بـ HTTP عاديًا على المنفذ الذي تحدده. للحصول على HTTPS (وهو **إلزامي** لعمل PWA والتثبيت على الهاتف):
1. ضع خادم وكيل عكسي (Nginx أو Caddy) أمامه.
2. فعّل شهادة مجانية عبر **Let's Encrypt / Certbot** (أو استخدم Caddy الذي يفعّلها تلقائيًا).
3. وجّه الدومين إلى الخادم الوكيل، والخادم الوكيل يوجّه إلى `localhost:3000`.

مثال إعداد Caddy بسيط (`Caddyfile`):
```
alameer-multimedia.com {
    reverse_proxy localhost:3000
}
```

### قاعدة البيانات في الإنتاج
لا حاجة لتثبيت أو تشغيل خادم قاعدة بيانات منفصل — الملف `data/ameer.db` (SQLite) يعمل من داخل نفس عملية Node. تأكد فقط من:
- وجود مجلد `data/` قابل للكتابة من طرف المستخدم الذي يشغّل Node.
- عمل نسخ احتياطي دوري لملف `data/ameer.db` (ملف واحد يكفي نسخه).

## 3. رفع المشروع للاستضافة

يعمل هذا المشروع على أي استضافة تدعم تشغيل عمليات Node.js طويلة الأمد (وليس فقط Serverless):
- **VPS عادي** (Hetzner, DigitalOcean, Contabo...): ارفع الكود عبر Git أو SFTP، ثبّت Node 22، شغّل بـ pm2 خلف Nginx/Caddy كما بالأعلى.
- **Railway / Render / Fly.io**: اربط مستودع Git، اضبط أمر التشغيل `node server.js`، وتأكد أن القرص الذي يحفظ فيه `data/` دائم (Persistent Volume) حتى لا تُفقد قاعدة البيانات عند كل نشر.

> ملاحظة: منصات الاستضافة الثابتة (Static Hosting) مثل GitHub Pages أو Netlify **لا تصلح وحدها** لأن المشروع يحتاج خادم Node يعمل باستمرار لتشغيل الـ API وقاعدة البيانات.

---

## 4. ربط الدومين

1. من لوحة تحكم مزوّد الدومين، أضف سجل `A` يشير إلى IP الخادم (أو `CNAME` إذا كانت الاستضافة تعطيك نطاقًا).
2. اضبط الخادم الوكيل (Nginx/Caddy) ليستقبل طلبات هذا الدومين ويحوّلها إلى `localhost:3000`.
3. فعّل HTTPS كما في القسم السابق — Caddy يفعل ذلك تلقائيًا بمجرد كتابة اسم الدومين في إعداداته.

---

## 5. إنشاء حساب المدير الأول

يحدث تلقائيًا عند أول تشغيل للخادم (راجع القسم 1). لإضافة مدير إضافي لاحقًا، سجّل الدخول بالحساب الحالي ثم استخدم مباشرة استعلام SQL بسيطًا، أو اطلب إضافة صفحة "إدارة المستخدمين" لاحقًا للوحة التحكم (الجدول `users` جاهز في قاعدة البيانات بحقل `role` يدعم `super_admin` / `admin` / `editor`).

## 6. تثبيت التطبيق (PWA)

بعد نشر الموقع على HTTPS:

**Android (Chrome):**
سيظهر شريط "تثبيت التطبيق" أسفل الصفحة تلقائيًا (أو من قائمة المتصفح ⋮ ← "تثبيت التطبيق" / "إضافة إلى الشاشة الرئيسية").

**iPhone (Safari):**
لا يدعم iOS نافذة التثبيت التلقائية؛ الطريقة اليدوية:
1. افتح الموقع في **Safari**.
2. اضغط زر المشاركة (المربع مع السهم للأعلى).
3. اختر **"إضافة إلى الشاشة الرئيسية"**.

**Windows / Desktop (Chrome أو Edge):**
اضغط أيقونة التثبيت ⊕ الظاهرة داخل شريط العنوان، أو من قائمة المتصفح ← "تثبيت الأمير للمالتي ميديا".

## 7. هيكل المشروع

```
al-ameer/
├── server.js         # الخادم الرئيسي + كل مسارات API
├── db.js             # الاتصال بقاعدة البيانات + الجداول + البيانات الافتراضية
├── auth.js           # جلسات الدخول الموقّعة (بديل JWT، بدون مكتبات خارجية)
├── upload.js         # استقبال وحفظ الملفات المرفوعة
├── public/            # الموقع العام (الواجهة)
│   ├── index.html / styles.css / app.js
│   ├── manifest.webmanifest / sw.js / offline.html   # PWA
│   └── uploads/       # الصور والفيديوهات المرفوعة
├── admin/              # لوحة تحكم المدير (محمية بتسجيل الدخول)
│   ├── login.html / dashboard.html / admin.css / admin.js
└── data/
    ├── ameer.db        # قاعدة البيانات (لا تُرفع لِـ Git)
    └── .session-secret # سر توقيع الجلسات (لا يُرفع لِـ Git)
```

## 8. الاختبارات التي أُجريت

تم تشغيل الخادم فعليًا واختبار كل ما يلي بنجاح عبر طلبات حقيقية على قاعدة البيانات:
تسجيل الدخول، حماية `/admin` ومسارات `/api` المحمية، إضافة/تعديل/حذف خدمة، إضافة/تعديل/حذف مشروع في المعرض، استقبال طلب عميل جديد من الموقع العام وظهوره فورًا في لوحة التحكم، تحديث حالة الطلب، إرسال رسالة تواصل، رفع ملف، تعديل إعدادات الموقع وظهورها فورًا في الواجهة، تسجيل الخروج والتأكد من عدم إمكانية الوصول للمسارات المحمية بعده.

## ملاحظة أمنية

لا توجد أي كلمات مرور أو مفاتيح سرية مكتوبة داخل الكود المصدري. كلمة مرور المدير الأول تُطبع مرة واحدة فقط في الطرفية عند أول تشغيل وتُخزَّن بعدها بصيغة مُجزّأة (scrypt hash) فقط — لا يمكن استرجاعها كنص عادي من قاعدة البيانات.
